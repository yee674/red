# 部署成「关掉电脑也能访问」的公网网址

> 你在本机跑，电脑一关别人就打不开 —— 因为网站其实跑在你电脑上。
> 要让网址一直在，必须把程序放到**一台常年开机的公网服务器**上（免费平台也行）。
>
> **注册账号这一步必须你本人做**（邮箱 / 验证码 / 实名，我不能代注册）。
> 但工程我已经改造成「上传即跑」：Linux 能编译 C 就编译，不能就自动退化，不会白屏。

---

## 方案 A：Hugging Face Spaces（最快，免 Git）

1. 打开 <https://huggingface.co/join> 注册（邮箱 → 验证链接 → 设置用户名）。
2. 登录后点右上头像 → **New Space**：
   - **Space name**：`redtrace-ai`（随意，会进网址）
   - **License**：MIT
   - **Select the Space SDK**：**Streamlit**
   - **Basic / CPU** → **Create Space**
3. 进入 Space 后点 **Files** → **Add file** → **Upload files**，
   把 **`红脉智谱-云端上传包.zip` 解压后的全部内容**（不是 zip 本身）整个拖进去：
   ```
   app.py  c_core.py  py_graph.py  graph.c  ui_graph.py  ui_map.py
   report.py  custom_route.py  kg.json  requirements.txt  packages.txt
   runtime.txt  README.md
   materials/  assets/  content/  static/  .streamlit/
   ```
   > 拖文件夹时注意勾选「保持目录结构」；`.streamlit/config.toml` 若网页上传不支持隐藏目录，
   > 可以跳过 —— 只是主题配色会回到默认，功能不受影响。
4. 点 **Commit changes**，等 1–3 分钟构建。
5. 右上 **App** 标签页就是你的公网网址：
   `https://huggingface.co/spaces/<你的用户名>/redtrace-ai`
6. 建议把 **Settings → Space hardware** 保持 CPU Basic（免费）；免费空间一段时间没人访问会休眠，
   有人打开时自动唤醒（约 30 秒），**网址不会变**。

### 关于 C 内核

上传包里的 `packages.txt` 内容是一行 `build-essential`，HF 构建时会装 gcc，
第一次启动就用 gcc 编译 `graph.c` 生成 `libgraph.so` —— 也就是**云端跑的也是 C 内核**。
万一宿主机没有 gcc / 编译失败，程序会自动退化为纯 Python 实现（`py_graph.py`），功能一模一样，
只是页面里「内核引擎」会显示 Python 兜底。

## 方案 B：Streamlit Community Cloud

1. 注册 GitHub → 新建仓库（Public）→ 把 **上传包解压后的内容** 上传（网页 Upload files 即可，不用命令行）。
2. 打开 <https://share.streamlit.io/> → 用 GitHub 登录 → **New app** → 选仓库 / 分支 `main` / 主文件 `app.py`。
3. **Deploy**，等 2–5 分钟，得到 `https://<应用名>.streamlit.app` 的网址。
4. 平台会自动读 `requirements.txt` 装依赖；如果它的镜像没有 gcc，就自动用 Python 兜底。

## 方案 C：自己的云服务器（最稳，能绑域名）

1. 买一台 Linux 云服务器（Ubuntu 22.04，2C2G 起步），装宝塔面板或直接用命令行。
2. 把「上传包」解压到 `/opt/redtrace`，然后：
   ```bash
   cd /opt/redtrace
   apt update && apt install -y python3-venv build-essential   # build-essential 供 gcc 编译 C
   python3 -m venv .venv && . .venv/bin/activate
   pip install -r requirements.txt
   streamlit run app.py --server.address 0.0.0.0 --server.port 8501
   ```
3. 用 systemd 或 `nohup` 让它后台常驻（关掉 SSH 也不停）：
   ```bash
   nohup .venv/bin/streamlit run app.py --server.address 0.0.0.0 --server.port 8501 > app.log 2>&1 &
   ```
4. 云厂商控制台放行 8501 端口，访问 `http://服务器公网IP:8501`；
   有域名就加一条 Nginx 反向代理 + HTTPS。

## 云端会遇到的三个问题（都已处理）

| 问题 | 处理方式 |
| --- | --- |
| 云平台是 Linux，跑不了 Windows 的 `graph.dll` | 启动时用 `graph.c` 自动编译 `libgraph.so`；编译不了就退化到 `py_graph.py` |
| 部分平台应用目录只读 | `nodes.txt` / `edges.txt` / `_runtime` 自动改写/复制到临时目录 |
| 免费空间会休眠 | 网址不变，首次访问自动唤醒（约 30 秒），演示前先打开一次预热 |

## 想确认云端用的哪个引擎

页面侧边栏 → 开发者面板（需环境变量 `RED_AGENT_DEV=1`）→ 「C 语言内核」里会写
`内核引擎：C 内核（graph.dll）` 或 `Python 兜底（未编译 C）`。
也可以直接看问答页「两点关系查询」的耗时标注：C 内核显示「C 语言 BFS 耗时」。
