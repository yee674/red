# 局域网部署（离线也能让别人用）

> 一句话：**你的电脑当服务器，同一 Wi-Fi 下的手机/电脑打开一个网址就能用。不需要连接外网。**

---

## 三步开起来

| 步骤 | 做什么 |
| --- | --- |
| 1 | 双击 **`启动局域网服务.bat`**（在上一层目录会自动找到 Python 环境） |
| 2 | 窗口里会打印出类似 `http://192.168.1.23:8501` 的地址，并生成 **`访问入口.html`** 与 **`访问二维码.png`** |
| 3 | 把二维码投屏 / 念一下地址，其他人手机连**同一个 Wi-Fi**，扫码或输入地址即可 |

第一次启动如果 Windows 弹出「防火墙已阻止此应用的部分功能」，**点允许访问**；
或者右键 **`允许防火墙放行.bat` → 以管理员身份运行**，它会永久放行 8501 端口。

停止服务：关掉那个黑窗口，或按 `Ctrl + C`。

## 为什么断网也能用

| 可能的联网依赖 | 本项目怎么处理 |
| --- | --- |
| 网页框架、字体、图标 | 全部来自本机 Streamlit 与系统字体，不走 CDN |
| 背景图 | `assets/bg.jpg` 由服务端读成 base64 内联进 CSS |
| 配图 | 本地 `assets/*.jpg`，地图弹窗里的照片也是压成 base64 内联 |
| 图谱可视化 | 自写的 canvas 力导图，无第三方库 |
| 地图底图 | **唯一需要外网的部分**：底图瓦片来自 OpenStreetMap；断网时自动降级为「深色底 + 地标 + 路线虚线」，点位、弹窗、照片、简介仍然全部可用 |
| 二维码 | 启动时用本机库生成静态 PNG，之后不再联网 |

> 也就是说：断网只影响地图**底图**，不影响任何功能与数据。

## 其他人访问不到？按这个顺序查

1. **是不是同一个网络**：手机连的是 Wi-Fi，电脑插的是网线但另一个路由器 → 不通。
   让电脑和手机都连同一个 Wi-Fi（或同一个交换机）。
2. **防火墙**：第一次启动没点「允许」→ 右键 `允许防火墙放行.bat` 用管理员运行。
3. **校园网/公共 Wi-Fi 的 AP 隔离**：有些学校网络禁止设备互访。
   解决：用手机开热点让电脑连上，或换一个家用路由器。
4. **地址不对**：电脑有多个网卡（VPN、虚拟网卡）时，`启动局域网服务.bat` 会列出「主地址 + 备用」，
   优先试主地址；都不行就在窗口里看 `Network URL` 那一行。
5. **服务关了**：黑窗口一关，所有人立即打不开。

## 现场演示的小技巧

- 把 **`访问入口.html`** 双击打开，投到大屏：上面有大号地址 + 二维码 + 注意事项，比念 IP 快。
- 多台设备同时用没问题：每个人的对话是**独立会话**（各自的历史互不影响），图谱与资料是共享只读的。
- 想换端口：编辑 `启动局域网服务.bat` 里的 `--server.port 8501`，防火墙脚本里的端口也一起改。
- 完全不想让别人连、只想本机演示：回到上一层双击 `启动红脉智谱.bat`（或 `start.bat`）即可，它只监听本机。

## 如果需要真正的「公网可访问」

那必须有一台公网服务器或内网穿透服务（如 cloudflared / frp），本质是**要联网**的，
和「不联网也能用」是互斥的两种模式。本目录只负责离线 + 局域网这一种。
